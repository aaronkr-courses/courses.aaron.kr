An advanced class taken in the hope of earning **college credit** by passing the AP Computer Science A exam in May. The course covered all the topics outlined on the College Board AP course website and in its sample syllabi, using **Java**:

- Data types and program logic
- Arrays
- Objects and classes
- Basic algorithms — sorting and searching
- Recursion
