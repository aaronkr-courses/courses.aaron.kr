A deep dive into the essentials of **website development**. We begin with HTML, CSS, and JavaScript — the foundational web languages — take JavaScript further with **jQuery**, build "real" sites with **Bootstrap**, and then look at modern web and app development with **React** (and a peek at React Native). Along the way, **Git and GitHub** are introduced to save and share code, and we talk about databases (Firebase) and APIs to see how the largest websites in the world work.

**Course sections:** I. Static websites (HTML + CSS) · II. Functional websites (JavaScript + jQuery + Bootstrap) · III. Web apps (React) · IV. Mobile apps (React Native)

**Projects:** school profile (HTML) · personal site (HTML + CSS) · collaborative class page (Git) · browser game (JavaScript) · app landing page (jQuery + Bootstrap) · web app (React) · final project.

**Materials:** [CodePen](https://codepen.io) for quick-start practice sites, [Codecademy](https://www.codecademy.com) for reference and practice projects, and [GitHub](https://github.com) to store all website and app code.
