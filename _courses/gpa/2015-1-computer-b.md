A deep dive into the essentials of **website development**, from static pages all the way to databases, APIs, and mobile apps. The goal is a solid foundation of programming terms, concepts, and best practices that empowers students — whether that means starting a simple blog, building an Internet business, or developing smartphone applications.

**Section I — Basic websites:** HTML5 (structure) · CSS3 (style) · JavaScript (functionality)
**Section II — Dynamic websites:** jQuery · Twitter Bootstrap · WordPress (+ WooCommerce)
**Section III — Powerful websites:** PHP · MySQL · APIs (Google Maps & Twitter)
**Section IV — Mobile apps:** HTML5 mobile apps with jQuery Mobile & Cordova (iOS + Android)

**Projects:** Hello World site · BBC News site replica · reaction-time browser game · CodePlayer · app landing page · WordPress blog · online store (WooCommerce) · weather search (PHP) · secret diary (MySQL) · postcode finder (Google API) · Twitter timeline · drawing app (mobile).

**Materials:** [Codecademy](https://www.codecademy.com) for reference, alongside the Udemy *Complete Web Developer Course*. All links and homework were posted on the class homepage, and students wrote a weekly reflection (Google Drive, later WordPress).
