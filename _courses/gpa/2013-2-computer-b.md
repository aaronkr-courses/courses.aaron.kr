Computer coding is quickly becoming the "new literacy." This course introduces students to some of the simplest and most enjoyable programming languages available — **HTML5, CSS3, and JavaScript**. Students learn to build the structure of websites (HTML5), lay out and style them (CSS3), and add functionality — games, plugins, and widgets — with JavaScript. By the end of the course, students should be comfortable with computer code, syntax, and basic programming concepts.

**Course sections:** HTML5 · CSS3 · JavaScript · PHP (if time) · Final project — *your own* website. The final test also included a short animation in **Alice3**.

**Materials:** class materials online, drawing on concepts from SitePoint's web design books; class time is given to work on the school computers.

*Originally planned as "Building Mobile Applications" (Android & iOS); the course was taught as introductory web programming instead. Reconstructed from the actual syllabus, 18-week overview, and final test.*
