HTML5, CSS3, and JavaScript are the de facto programming languages of the Internet — the foundation of web application development, which is itself the gateway to smartphone app development. This course builds a solid foundation of programming terms, concepts, and best practices using the web languages, plus **Alice3** and **Quintus** game development.

By the end of the course, students will demonstrate:

- Knowledge of the basic programming languages (keywords & syntax) of the Internet
- The ability to create a basic website structure, style it, and add functionality
- Coding best practices for commenting and readability
- The ability to debug and modify website code
- A basic understanding of object-oriented programming

**Course sections:** I. HTML · II. CSS · III. Alice3 · IV. JavaScript · V. Game development

HTML5 and CSS3 are the quickest languages to learn and make an excellent primer. Alice3 introduces object-oriented programming in a virtual world that feels more like making an animated movie than programming. JavaScript takes OOP further with arrays, loops, and data types. The final project — an HTML5 game built with the Quintus engine — puts everything together.

**Materials:** no textbook — [Codecademy](https://www.codecademy.com) is the "online textbook" for HTML, CSS, and JavaScript, with 19 graded coding projects and 3 coding quizzes. Additional resources: Mozilla Thimble, Alice3, WAMP Server, Quintus, Tiled, and OpenGameArt.org.
