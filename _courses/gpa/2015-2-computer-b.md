A deep dive into the essentials of **website development** with the three foundational web languages — **HTML5** (structure), **CSS3** (style), and **JavaScript** (functionality). These are the easiest languages to start with and an excellent primer for programming in general; the goal is a solid foundation of programming terms, concepts, and best practices.

**Course sections:** I. Site structure (HTML) · II. Site style (CSS) · III. Site functionality (JavaScript)

**Projects:** Hello World site · Codecademy HTML & CSS course · Korean news website · a 4-page template site (later extended with a store, purchase page, and JavaScript shopping cart) · Codecademy JavaScript course · finger-counting game · final website project.

**Materials:** [Codecademy](https://www.codecademy.com) is the primary reference; additional materials and all homework were posted on the class homepage.
