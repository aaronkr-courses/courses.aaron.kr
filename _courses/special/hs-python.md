영어 원어민 강사와 함께하는 파이썬 프로그래밍 특강입니다. Python 기초부터 응용까지 영어로 배우는 고등학교 방학 특강 프로그램입니다.


A summer crash course (나의 첫 파이썬) for high-school students, taught in English: installing Python and VS Code, variables and data types, lists, conditionals, dictionaries, user input and loops, functions, and classes — finishing with a small game project (Alien Invasion).
