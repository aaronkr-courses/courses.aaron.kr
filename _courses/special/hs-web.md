영어 원어민 강사와 함께하는 웹 프로그래밍 특강입니다. HTML, CSS, JavaScript 기초를 영어로 배우는 고등학교 방학 특강 프로그램입니다.


A summer crash course (나의 첫 웹프로그래밍) for high-school students, taught in English: HTML structure, text, lists, links, images, tables, forms and media, then CSS (color, typography, the box model), with code-along lessons on JavaScript, jQuery and a Bootstrap photo-gallery project.

📎 Full course site: [2023-aaronkr.github.io/web-crash-course](https://2023-aaronkr.github.io/web-crash-course/)
