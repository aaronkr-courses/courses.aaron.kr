{%- comment -%} Single source of truth for a course's Topic pill(s) (filter class + display label). Infers a single topic from the course's title, unless a `topic:` front-matter field is set, in which case it overrides auto-detection — and may list more than one topic as a comma-separated string (e.g. `topic: Systems, BioMed`) to tag a course with several. Each value accepts either the internal filter key (ai-tag, data, web, theory, systems, ee, biomed) or the human-readable label (AI/ML, Data, Web, Programming, Systems, EE, BioMed) — matched case- and punctuation-insensitively, since that's what most people will naturally type. Usage: {% include topic_tag.html course=c %} Assigns into the caller's scope (Jekyll's `include` shares scope with its caller, unlike `render`): _tc_list / _tl_list — parallel arrays, one entry per topic, in order. Loop them together to render one pill per topic: {%- for cls in _tc_list -%} {%- assign lbl = _tl_list[forloop.index0] -%} {{ lbl }} {%- endfor -%} _tc / _tl2 — first topic's class/label (kept for single-pill callers) _topics_str — all topic classes space-separated, e.g. "systems biomed" — use this for a `data-topic` filter attribute so a course matches if ANY of its topics is the active filter
